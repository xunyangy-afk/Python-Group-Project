## Run Instructions

Run the cleaning script from `Python-Group-Project/data-cleaning`:

```powershell
python clean_data.py
```

The script:

- reads raw parquet files from `data/raw/data`
- standardizes symbols, dates, filing types, and text fields
- flags suspicious values before removal
- preserves stock-price and share-count units
- writes cleaned CSV and parquet files
- writes an audit report to `data/processed/cleaning_report.json`

To download/import the data and validate the results, open and run:

```powershell
jupyter notebook cleaning.ipynb
```

The notebook checks:

- row counts before and after cleaning
- missing values before and after cleaning
- unique categorical values
- numeric min, max, and distributions
- duplicate counts
- flagged suspicious values
- actual rows before and after transformations
- whether the cleaned data still represents the real-world phenomenon correctly
